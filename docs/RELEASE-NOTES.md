# 0.19.0-rc.1 — Torchlit haven

The top-down homestead now sits among broken paving, moss or ash, dark pines and warm torchlight. Day and night use distinct courtyard tones; low-contrast edge shading adds depth while enemies remain in the foreground. Original native Canvas art requires no downloaded assets or new dependencies.

The compact framed HUD puts survived days, gold/timber and day/night conditions above separate farm and fence integrity bars. Both bars expose exact values to accessibility services and scale with system text size. The lighter build tabs and dispersed crew patrol fixes are retained. Controls, board touch geometry, combat, crop/economy rules, RNG and save schema 12 remain unchanged.

Android 8.0+ (API 26), versionCode 27. Required candidate gates: both JVM variants, builds/lint/package checks, API 26/35 native regression, four biome/phase captures, deterministic rendering/save-byte checks and original-certificate signed install-over testing. Observed evidence is recorded in TESTING.md and the release VERIFICATION.txt.
