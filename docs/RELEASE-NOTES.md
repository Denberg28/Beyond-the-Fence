# TAG: Zombie Survival Fantasy0.14.0-rc.1

Build controls now follow the way you prepare a haven: Fence, Farm, Mill, Crew, Supplies, Equipment. Fortification belongs to Fence; all potion/magic purchases and quick-slot assignment live in Supplies. Sections organize construction, upgrades and orders. A missing-market link takes you directly to Farm.

Parchment panels, timber frames and gold trim connect Build, equipment/slot selectors, arena, portal, help and options to the game theme.

World2 begins **Ashen March**, a first playable biome slice with charred pines, kiln ruins, ember-marked heavy foes, ashfall and the Cinder Regent. Ashfall slows approaches15% but increases Brute/Ironhide damage20%. Every fifth night brings ashfall; the Regent has10% more HP/damage. Four named25-day chapters frame the century. Existing quotas, progression, arenas and loot odds remain; later worlds currently reuse this biome.
